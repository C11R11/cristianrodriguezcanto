# First Post
*Published on 2026-05-11*

This is my first post on my new minimalist personal site. I'm using MkDocs with a custom CSS theme to achieve this "elevated card" look while keeping everything in Markdown.

## Why Markdown?
Markdown is much easier to write and maintain than raw HTML. By using MkDocs, I get the best of both worlds:
1.  **Ease of writing:** Simple text files.
2.  **Great design:** A clean, academic aesthetic.
